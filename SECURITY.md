# Security Policy

## Supported Versions

Only the `master` branch is currently receiving security updates.

| Version | Supported          |
| ------- | ------------------ |
| master  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to Het Soni via [hetsony143@gmail.com](mailto:hetsony143@gmail.com). All security vulnerabilities will be promptly addressed.

Please do **not** disclose the issue publicly until a fix has been released.
